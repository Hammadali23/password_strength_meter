Password Strength Meter
A simple, interactive Password Strength Meter built using Streamlit. This app evaluates the strength of a user-entered password in real-time and provides actionable feedback and suggestions to improve security. The password strength is evaluated based on the following criteria:

Minimum length (8 characters)

Presence of uppercase letters

Presence of lowercase letters

Inclusion of numbers (0-9)

Use of special characters (e.g., !@#$%^&*)
